Virginia Beach Town Center

A design study exploring how retail, residential, hotel, restaurants, parking and public space can be assembled vertically within a connected urban block framework.

LocationVirginia Beach, Virginia
DateSeptember 2004
StudyMixed use urban blocks

Project at a glance

01 · Block structure

Turn a large site into streets and blocks

Building edges define a finer-grained network of streets, internal drives and public-facing frontages instead of treating the site as one continuous parcel.

02 · Mixed use

Layer active uses vertically

Retail is concentrated at grade, while residential, hotel, restaurants and other uses appear above or beside parking and podium structures.

03 · Parking integration

Put large parking areas inside the block system

Parking structures occupy substantial portions of the interior while occupied uses line key edges and corners.

04 · Public realm

Use greens, terraces and bridges to connect pieces

Linear green spaces, terraces and bridge elements create a second layer of circulation and amenity across the mixed-use composition.
